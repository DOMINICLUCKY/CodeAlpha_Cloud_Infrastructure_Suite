# Cloud Infrastructure Suite

A full-stack web application demonstrating core cloud computing concepts, including cryptographic data deduplication, threat detection and mitigation, data encryption, and automated knowledge assistant integration.

---

## 🌟 Overview

The **Cloud Infrastructure Suite** brings together three essential cloud operational modules into a unified dashboard interface:

1. **Data Redundancy Engine:** Prevents duplicate data entry in cloud databases by generating and validating SHA-256 cryptographic hashes prior to insertion.
2. **SQL Injection Defense & AES-256 Security:** Secures sensitive user credentials using AES-256 encryption and filters inbound queries against known SQL injection attack vectors.
3. **Automated Assistant Engine:** An integrated, light-footprint chatbot trained on predefined cloud security and operational parameters to provide instant user support.

---

## ⚙️ Tech Stack

* **Backend:** Node.js, Express.js
* **Security & Cryptography:** Node.js Native `crypto` Module (SHA-256, AES-256-CBC)
* **Frontend:** HTML5, Modern JavaScript (Fetch API), Tailwind CSS
